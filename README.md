📊 Student Performance Dashboard

An interactive Student Performance Dashboard created using Microsoft Excel to analyze student performance, attendance, pass rates, and placement statistics.

🛠️ Tools & Features

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- KPI Cards
- Data Visualization
- Data Analysis

📈 Dashboard Analysis

The dashboard provides insights into:

- Overall student performance
- Attendance
- Pass percentage
- Placement statistics
- Male vs. female placement rates
- Subject-wise performance
